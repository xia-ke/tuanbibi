# 团比比 · 开发路线

## 产品目标

用户在同一城市搜索线下门店，通过平台授权数据或经允许的录入渠道，查看**同一门店、同一套餐、相同使用条件**的跨平台报价，并跳转至原平台核实购买。

不做代售、核销、不经许可的批量爬取或绕过各平台风控。

## MVP · 0.1

- [x] 城市与门店搜索
- [x] 响应式 Web UI
- [x] 严格按门店和套餐归组
- [x] 标价/优惠/费用以整数分计算
- [x] 演示数据隔离真实省钱结论
- [x] SQLite、管理员令牌、自动化测试、CI
- [ ] 实测两家真实门店、两个以上合法来源的数据路径

## 数据源 · 0.2（优先级 P0）

- [ ] 核查美团/点评、抖音、快手平台官方接口准入与可查范围
- [ ] 实现平台 Adapter 接口和授权令牌隔离
- [ ] 核验可售状态、有效期、用户领取资格、退款与预约条件
- [ ] 增加来源证据、审计记录、过期价格降级
- [ ] 至少两个平台的同款**授权真实报价**端到端验证

## 实用化 · 0.3

- [ ] 门店 POI 标准化与同名异店去重
- [ ] 套餐人数、规格、用餐日、时段、预约规则校验
- [ ] 真实价格历史、降价提醒
- [ ] 管理后台、登录 RBAC、审计和限流
- [ ] 上线时明确可比较的商品覆盖率

## 发布指标

1. 同一地址同一真实门店的匹配精度
2. 套餐内容、人数、使用条件的等价判断精度
3. 至少两个授权来源的商品覆盖率
4. 价格核验后真实可购买比例
5. 价格更新时间、来源信息的完整度

**上线门槛是稳定合法的数据接入，不是演示页面完成。**
